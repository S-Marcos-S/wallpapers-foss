## Sobre o Repositório

Coleção de papéis de parede projetados para celulares.

- **Imagens e Vídeos:** Catálogo com papéis de parede estáticos (WebP/JPG) e animados (Live Wallpapers em MP4).
- **Curadoria Inteligente:** Classificação de títulos, categorias e paletas de cores via IA.
- **Resoluções FullHD/2k/4k:** Armazenamento dos arquivos com 100% de fidelidade e miniaturas WebP otimizadas para carregamento rápido.

## Como Enviar Papéis de Parede Direto do Celular

Envie papéis de parede diretamente da galeria do seu smartphone usando Issues:

1. Abra a aba **Issues** do repositório no aplicativo do GitHub ou navegador mobile.
2. Toque em **New Issue** e selecione o modelo **Enviar Papéis de Parede**.
3. Anexe as imagens desejadas direto da galeria e toque em **Enviar**.
4. O GitHub Actions baixa as imagens em resolução original, gera miniaturas WebP, classifica tags e categorias via Google Gemini Flash e atualiza o catálogo automaticamente.
